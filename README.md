# Estoque Local para Windows

O Estoque Local é um aplicativo de catálogo, estoque e vendas para Windows x64. A versão **0.2.0.0 é candidata**.

## Instalar

1. Na página de [versões](https://github.com/LeoSchiavinatto/estoque-local-downloads/releases), baixe **Instalar-Estoque-Local.exe**.
2. Abra o arquivo no Windows e siga as instruções do instalador.
3. Abra **Estoque Local** pelo atalho criado na área de trabalho ou no menu Iniciar. O aplicativo abre no navegador.

Depois de baixar o instalador, você pode instalar e usar o aplicativo offline. As dependências vêm no pacote. Cada computador mantém seu próprio estoque. Os dados e as fotos ficam em um banco local, separado do navegador.

Em **Backup e configurações**, use **Configurar destino adicional** para escolher uma pasta em outro dispositivo, como um pendrive ou disco externo.

O **kit de validação offline** é opcional para quem vai testar a instalação em um Windows limpo. A aprovação pós-reinício está registrada. A validação em Windows limpo, offline e sem ferramentas de desenvolvimento permanece pendente.
